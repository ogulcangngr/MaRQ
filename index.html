Parameters
Point Cloud Parameters
Voxel size (0 = auto)
Grid cell size for downsampling; 0 picks it automatically from point density.
Field band (MAD ×)
How tightly the flat field plane is fit (robust MAD multiplier). Lower = stricter field selection. Leveling and orientation are referenced to this field, so there is no channel-floor percentile to set.
Crop pad X (units)
Extra distance added beyond the detected channel length on each end of the crop box, in point cloud units.
Crop pad Y (units)
Extra distance added beyond the detected channel width on each side of the crop box, in point cloud units.
Opening level fraction
0.10
Depth fraction used for the opening width/length measurement. 0.1 = top 10% of channel depth, close to where the channel meets the flat surface.
Floor width fraction
0.90
Depth fraction for the floor (narrowest) width — the channel bottom, where the nominal width is defined. 0.90 = bottom 10% of depth. Floor and opening widths are read at fixed levels off the mean cross-section, so they are comparable across surfaces.
Roughness eval area (floor)
0.50
Floor roughness strip width as a fraction of the channel width (central part of the floor). 0.5 = central 50%. The length is set below.
Floor eval length (units)
Length of the floor roughness strip along the channel axis, centered on the channel.
Field eval width (units)
Fixed width of the left/right field roughness strips. Their position is found automatically — placed just past the raised channel lip onto clean flat field — so only this fixed size needs setting, keeping measurements comparable across surfaces.
Field eval length (units)
Fixed length of the field roughness strips along the channel axis, centered on the channel.
Advanced Parameters
Edge margin
Distance from each edge to discard before analysis, removing boundary artifacts.
Grid resolution
Number of interpolation grid cells per axis for the surface heatmaps.
Smooth sigma
Gaussian blur radius on the interpolated grid; 0 disables smoothing.
Profile slices
Number of cross-section slices along the channel used for the width/length profile overlays and their scatter.
Skip rows
Number of header rows to skip when loading the point cloud file.
Gradient Parameters
Grid spacing (µm)
Physical size of each grid cell, in µm — set to the data (voxel) resolution. The same spacing is used for every comparison, so the gradient metrics (r_mag, etc.) are sampled identically and stay comparable across channels.
Smooth sigma (µm)
Gaussian blur (in µm) before computing gradients. A minimum of one grid cell is always applied for gradient stability.
Skip rows
Number of header rows to skip when loading the point cloud files.
