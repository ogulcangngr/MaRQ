Point Cloud Parameters
Voxel size (0 = auto)
Grid cell size for downsampling; 0 picks it automatically from point density.
Field band (MAD ×)
How tightly the flat field plane is fit (robust MAD multiplier). Lower = stricter field selection. Levelling and orientation are referenced to this field.
Crop pad X (units)
Extra distance added beyond the detected channel length on each end of the crop box, in point cloud units.
Crop pad Y (units)
Extra distance added beyond the detected channel width on each side of the crop box, in point cloud units.
Opening level fraction
0.10
Depth fraction used for the opening width/length measurement. 0.1 = top 10% of channel depth, close to where the channel meets the flat surface.
Floor width fraction
0.90
Depth fraction for the floor (narrowest) width, the channel bottom where the nominal width is defined. 0.90 = bottom 10% of depth. Floor and opening widths are read at fixed levels off the mean cross-section, so they are comparable across surfaces.
Roughness eval area (floor)
0.50
Floor roughness strip width as a fraction of the channel width (central part of the floor). 0.5 = central 50%. The length is set below.
Floor eval length (units)
Length of the floor roughness strip along the channel axis, centred on the channel.
Field eval width (units)
Fixed width of the left/right field roughness strips. Their position is found automatically, just past the raised channel lip on clean flat field, so only this fixed size needs setting, keeping measurements comparable across surfaces.
Field eval length (units)
Fixed length of the field roughness strips along the channel axis, centred on the channel.
Advanced Parameters
Edge margin
Distance from each edge to discard before analysis, removing boundary artifacts.
Display cell size (0 = auto)
Side of the square cells of the height maps and the 3D view, in point cloud units. Display only: the geometry and roughness are computed from the points. 0 chooses the finest cell (never below the voxel size) that keeps each map within 160 000 cells.
Smooth sigma
Gaussian blur radius on the display grids, in cells; 0 disables smoothing.
Profile slices
Number of cross-section slices along the channel used for the width/length profile overlays and their scatter.
Skip rows
Number of header rows to skip when loading the point cloud file.
Comparison Parameters
Grid spacing (µm)
Physical size of each grid cell of the common grid, in µm. RQd is defined at a stated cell size; keep the same value for every comparison so the correlations stay comparable.
Smooth sigma (µm)
Gaussian blur (in µm) before computing the slopes. A minimum of one grid cell is always applied for gradient stability.
Skip rows
Number of header rows to skip when loading the point cloud files.

About MaRQ

MaRQ, the Microchannel and Replication Quality Analyzer, version 1.0. It measures microchannels in optical-profilometry point clouds and grades how faithfully a channel has been replicated from a mould insert into a moulded part, with the height correlation RQ, the directional slope correlations RQdx and RQdy, and RQd, the slope-magnitude correlation over the channel interior.

Please cite
M. O. Güngör, J. Charmet, E. Yıldırım, A 3D slope-correlation metric and workflow for grading microchannel replication quality, Measurement (submitted, 2026).

The metrics
RQ: Pearson correlation of the two height maps over the channel-interior mask. RQdx, RQdy: correlations of the signed slopes along and across the channel. RQd: correlation of the slope-magnitude maps |∇Z| at the stated grid cell size (5 µm in the paper); it is the grading metric because it responds to sidewall shape where height correlation saturates.
